# Dark Mode — PassReset Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agregar toggle manual dark/light mode con persistencia en `localStorage`.

**Architecture:** CSS variables en `:root` (light) sobreescritas por `[data-theme="dark"]`; un hook `useTheme` aplica el atributo a `<html>` y persiste en `localStorage`; un `<script>` inline en `index.html` previene el flash al recargar.

**Tech Stack:** React 18, TypeScript, CSS plano (sin framework UI), Vite 5.

## Global Constraints

- Sin dependencias nuevas (no instalar nada).
- El header (`background: #1e2d4f`) y los badges de estado (rojo/verde/amarillo) NO cambian entre modos.
- El inline style del `ServerFilter` select y del botón reload del header permanecen como están (están dentro del header siempre oscuro).
- Archivo de entrada del servicio: `server.cjs` (CommonJS).
- Build: `npm run build` desde `C:\apps\dashboards\PassReset\`.

## Task 2: Hook `useTheme`

**Files:**
- Create: `src/hooks/useTheme.ts`

**Interfaces:**
- Produce: `useTheme(): { theme: 'light' | 'dark'; toggle: () => void }` — importado en `App.tsx`.

- [ ] **Step 1: Crear `src/hooks/useTheme.ts`**

```ts
import { useState, useEffect } from 'react'

type Theme = 'light' | 'dark'

function applyTheme(theme: Theme) {
  document.documentElement.setAttribute('data-theme', theme)
}

export function useTheme() {
  const [theme, setTheme] = useState<Theme>(() => {
    const saved = localStorage.getItem('theme') as Theme | null
    return saved === 'dark' ? 'dark' : 'light'
  })

  useEffect(() => {
    applyTheme(theme)
    localStorage.setItem('theme', theme)
  }, [theme])

  const toggle = () => setTheme(t => t === 'light' ? 'dark' : 'light')

  return { theme, toggle }
}
```

- [ ] **Step 2: Verificar que el hook aplica el atributo**

Con el dev server corriendo, abrir la consola del navegador y ejecutar:
```js

```
Debe retornar `"light"` (o `"dark"` si ya había algo en localStorage).

- [ ] **Step 1: Agregar script inline en `index.html`**

Reemplazar el contenido actual de `index.html` con:

```html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>PassReset — Gestión de Contraseñas</title>
    <script>
      (function() {
        var t = localStorage.getItem('theme');
        if (t === 'dark') document.documentElement.setAttribute('data-theme', 'dark');
      })();
    </script>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```
